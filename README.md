# FertCalc PWA

Pacote pronto para GitHub Pages.

## Publicar
1. Crie um repositório no GitHub.
2. Envie **todos os arquivos deste pacote para a raiz do repositório**.
3. Abra `Settings > Pages`.
4. Em `Build and deployment`, selecione `Deploy from a branch`.
5. Escolha `main` e `/ (root)` e salve.
6. Abra a URL HTTPS criada pelo GitHub Pages no Chrome do Android.
7. Use `Instalar app` ou `Adicionar à tela inicial`.

Para uma atualização do app, substitua os arquivos no mesmo repositório. O service worker usa o cache `fertcalc-v4`.
